# Josh English Academy

Premium public website plus a secure admin dashboard for Josh English Academy.

## Stack

- Next.js frontend
- Express backend API
- MongoDB with Mongoose
- Cookie-based JWT admin authentication

## Run locally

1. Copy `.env.example` to `.env.local` for Next.js and `.env` for the Express server.
2. Install dependencies with `npm install`.
3. Start MongoDB locally or point `MONGODB_URI` to MongoDB Atlas.
4. Run the backend with `npm run server`.
5. Run the frontend with `npm run dev`.
